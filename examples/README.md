# Exemplos de resultados reais

Estes arquivos foram extraídos do pacote de resultados do Raspberry Pi 4 de 8 GB utilizado no ensaio de 15/10/2026, e são **materiais de referência**, não uma promessa de desempenho em outros equipamentos.

`resumo_servidor_8gb_20261015.json` contém os metadados e estatísticas dos dez cenários da bateria de 1,5 e 1,8 GHz. `gpu_preflight_v3d_20261015.log` contém uma verificação V3D do ensaio original.

Os CSVs completos não foram incluídos no repositório: devem permanecer como artefatos de resultados ou serem disponibilizados em uma release separada, após revisão de dados sensíveis.
